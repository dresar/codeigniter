Petunjuk Upload Template

  • File HTML harus menggunakan variabel Django template seperti: {% verbatim %}{{ invitation.groom_name }}{% endverbatim %}
  • File HTML akan disimpan di folder templates/invited/ (TIDAK di media)
  • File CSS akan di-rename otomatis menjadi style1.css, style2.css, dll dan disimpan di static/templates/css/ (TIDAK di media)
  • File JS akan di-rename otomatis menjadi script1.js, script2.js, dll dan disimpan di static/templates/js/ (TIDAK di media)
  • File Images disimpan di media/templates/images/ (hanya images di media)
  • Di template HTML, gunakan {% verbatim %}{% load static %}{% endverbatim %} dan {% verbatim %}{% static 'templates/css/template-slug/style1.css' %}{% endverbatim %}
  • Gunakan context variables: invitation, galleries, rsvp_form, guest_name
